The film verb is a thin wrapper, so drive the runner yourself and skip a layer:

```bash
rm -rf test-results/
PW_PROVE_CLIP=1 PW_PROVE_W=1600 PW_PROVE_H=900 \
  npx playwright test e2e/reports.spec.ts \
  --config=e2e/playwright.proof.config.ts \
  --project=chromium \
  --reporter=html
```

No concurrency flag is passed, so Playwright uses its default of cores/2.
