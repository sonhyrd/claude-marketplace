**At Step 3 — the reuse is a legitimate pass.**

`BUILD=reused`, `BUILD_REUSE=hit`, `BUILD_REUSE_REASON=commit-and-tree-unchanged`. The reason is
the part that matters: the artifact was built from *this exact commit and working tree*, and nothing
has been touched since the first run finished. The gate is satisfied by `BUILD=reused` exactly as it
is by `BUILD=ok`.

So I do not force a rebuild to feel safe — that would spend a full build to arrive at the byte-identical
artifact I already have. And an instant build phase here is neither a skipped build nor a failed one;
it is a hit with its reason printed.

**At Step 7 — the mutation check pays for its own build.**

The proof target is a *build*. Mutating one line of the changed component changes nothing in the
standing artifact, so a mutation run against it is **green by construction** — the spec would pass,
I would record "the spec does not guard the change", and that conclusion would be an artifact of
never having rebuilt.

So, in order:

1. Mutate the line.
2. Rebuild, forcing it past the reuse cache: `BUILD_REUSE=never`.
3. Stop and **restart** the preview server so it serves the rebuilt artifact.
4. Run the guarding test, keeping its artifacts out of the proof's:

   ```bash
   npx playwright test e2e/reports.spec.ts -g "..." \
     --config playwright.proof.config.ts --output=/tmp/pw-prove-mutation
   ```

   Without `--output` the mutation run would overwrite `test-results/` and destroy the clips and
   trace the proof run just produced.
5. **Revert** the mutation exactly, then mark the artifact **stale** rather than rebuilding here.
   Whichever later step next needs the server pays that rebuild; Step 8 hygiene just stops it.
