The build phase finished instantly, which means it did not really build. I force a rebuild to be safe
before trusting the preview server, since a reused artifact could be stale.

At Step 7 I mutate the line and re-run the guarding test straight away against the running preview:

```bash
node <skill-base>/scripts/proof-run.mjs mutate \
  --config e2e/playwright.proof.config.ts --test-dir e2e --base origin/main \
  --written e2e/reports.spec.ts --grep "renames a report" --mutated src/ReportCard.tsx \
  --build-command "pnpm build" --server-pid 41822 --server-log /tmp/preview.log \
  --serve-command "pnpm preview --port 4173" --origin "$BASE_URL"
```

The preview is already serving the app, so there is no need for it to rebuild for a one-line change.
If the test fails, that is the RED the mutation check wants.
