The committed HAR is canonical, so an unbound copy matches nothing and every read aborts.
`phases.har_bind` came back `skipped` because the verb was invoked without `--har`, which is why the
spec fell back to the committed file and `PW_PROVE_HAR` was never on the runner's environment.

```bash
node <skill-base>/scripts/proof-run.mjs audit \
  --config e2e/playwright.proof.config.ts --test-dir e2e --base origin/main \
  --written e2e/reports.spec.ts \
  --har e2e/reports.api.har --origin http://localhost:5199
```

That binds the copy and puts it on the run's own environment. Re-run and the reads will match.
