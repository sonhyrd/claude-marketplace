**Scenarios**

## Scenario 1: saving sends the built upsert payload
- Given: the custom-scripts settings page with two locales filled and one blank
- When: the user saves
- Then: the request the browser sends carries the trimmed, blank-dropped payload

## Scenario 2: the saved custom scripts survive a reload
- Given: scripts saved in scenario 1
- When: the page is reloaded
- Then: the persisted values render

The behaviours a unit test cannot see stay their own scenarios: the request the browser actually
sends, the DOM state, feature-flag gating and persistence across a reload. The completion report
lists the three folded ACs explicitly with their `already covered:` marker, so a reader can see
