- **Then:** the intercepted upsert request body contains the trimmed value, carries no entry for the whitespace-only locale, and the editor shows its saved state

### Scenario 2: emptying every locale removes the key
- **Given:** the editor is open with a key that has values in two locales
- **When:** the user clears both values and saves
- **Then:** the upsert request body contains no entry for that key, and the key no longer appears in the editor's key list
