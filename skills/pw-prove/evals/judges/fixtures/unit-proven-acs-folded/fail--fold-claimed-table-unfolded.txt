**Scenarios**

### Scenario 1: padded values save clean
- Given: the editor with one padded value
- When: the user saves
- Then: the stored value has no padding

### Scenario 2: blank locales disappear
- Given: the editor with one blank locale
- When: the user saves
- Then: the payload carries no entry for it

### Scenario 3: an all-blank key disappears
- Given: the editor with a key whose locales are all blank
- When: the user saves
- Then: the payload carries no entry for that key

### Scenario 4: the save request reaches the API
- Given: the editor with two locales filled
- When: the user saves
- Then: the request the browser sends carries the built payload

The behaviours a unit test cannot see — the request the browser actually sends, DOM state, flag
gating and persistence — keep their own scenarios.
